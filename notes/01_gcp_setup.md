# Phase 01 – Google Cloud Platform Setup

## Objective

The objective of this phase is to provision the Google Cloud infrastructure required to support the data engineering pipeline.

The infrastructure consists of a virtual machine for workflow orchestration, cloud object storage for raw datasets, BigQuery as the cloud data warehouse, and IAM for secure authentication.
