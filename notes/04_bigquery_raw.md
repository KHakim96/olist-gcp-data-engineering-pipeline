# Phase 04 – BigQuery Raw Layer

## Objective

The objective of this phase is to build the Raw Layer of the cloud data warehouse using Google BigQuery.

During this phase, raw datasets stored inside Google Cloud Storage are prepared for analytics by:

- Creating BigQuery datasets
- Generating table schemas
- Creating BigQuery tables
- Loading Olist CSV datasets
- Loading historical weather datasets

At the end of this phase, every raw data source is available inside BigQuery.

# Challenges

Issue

google-cloud-bigquery package missing.

Solution

Installed

google-cloud-bigquery

---

Issue

Weather JSON generated as JSON Array.

Problem

BigQuery requires

NEWLINE_DELIMITED_JSON

Solution

Modified weather downloader.

Instead of

json.dump(...)

Each record is written individually.

Example

for record in weather:

write(record)

write(newline)

---

Issue

Weather schema generator failed.

Reason

Schema generator expected JSON Array.

Solution

Read only the first NDJSON line.

Infer schema from that record.

---

Issue

CSV Loader failed for review dataset.

Reason

Quoted review comments contained embedded newlines.

Solution

Added

allow_quoted_newlines=True

Used existing table schema during loading.

Problem resolved.
